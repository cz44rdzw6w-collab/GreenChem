# GreenChemAI

**GreenChemAI** — «Жасыл химияға кіріспе» университеттік курсына арналған интерактивті білім беру платформасы. Оқыту **Case Study** әдістемесі мен **жасанды интеллект** құралдарына негізделген. Интерфейс толығымен қазақ тілінде.

## Бөлімдер

| Бөлім | Мазмұны |
|---|---|
| **Басты бет** | Курсқа кіріспе, прогресс колбасы мен белгілер, студент профилі, «AI-ды оқуда қолданудың 6 кезеңі» әдістеме жолы, модульдер |
| **Лекциялар** | Мұғалім `public/lectures/` қалтасына жүктеген PDF, PPTX, DOCX, бейнелер және YouTube сілтемелері: сайтта қарау немесе жүктеу |

Прогресс браузердің `localStorage`-інде сақталады (тіркелу қажет емес).

### Нәтижелерді ұйымдастырушыға жіберу

Студент тест немесе кейс тапсырған сайын нәтиже мен толық жауаптар **Google Sheets кестесіне** жазылып, **ұйымдастырушының поштасына** хат келеді (Google Apps Script арқылы, тегін, серверсіз). Баптау: [docs/teacher-guide.md](docs/teacher-guide.md) → содан кейін `public/js/config.js` ішінде `submitUrl` пен `organizerEmail` толтырылады.

Лекция қосу мен тест сұрақтарын өзгерту де сол нұсқаулықта сипатталған.

## Іске қосу

Node.js 18+ қажет.

```bash
npm install
npm start          # http://localhost:3000
npm test           # химиялық есептеулер тесттері
```

### AI режимі

`ANTHROPIC_API_KEY` орнатылса, AI көмекші мен «AI арқылы терең бағалау» батырмасы серверде Claude моделімен (`claude-opus-5-5`) жұмыс істейді:

```bash
ANTHROPIC_API_KEY=sk-ant-... npm start
```

Кілт болмаса, платформа толық жұмыс істейді: AI көмекші браузердегі қазақша білім базасы мен химиялық есептеуішке ауысады, кейстер рубрика бойынша автоматты бағаланады. Кілт тек серверде сақталады, браузерге жіберілмейді.

## Деплой

- **Node сервері (толық, AI-мен):** Render, Railway, Fly.io және т.б. — `npm start`, ортада `ANTHROPIC_API_KEY` және (қаласаңыз) `PORT` орнатыңыз.
- **Docker:** `docker build -t greenchemai . && docker run -p 3000:3000 -e ANTHROPIC_API_KEY=... greenchemai`
- **GitHub Pages (статикалық, офлайн AI):** `.github/workflows/pages.yml` `main` тармағына push кезінде `public/` қалтасын жариялайды (Settings → Pages → Source: GitHub Actions).
