# Мұғалімге арналған нұсқаулық

Бұл құжатта үш нәрсе түсіндіріледі:

1. Студент жауаптарын Google кестесіне жинау және оларды поштаға алу.
2. Лекция материалдарын қосу.
3. Тест сұрақтарын өзгерту.

---

## 1. Жауаптарды Google Sheets-ке жинау және поштаға алу

Студент тест немесе кейс тапсырған сайын:

- Google кестеңізге студенттің аты-жөні, тобы, нәтижесі және толық жауаптары бар жаңа жол қосылады;
- сіздің поштаңызға нәтиже мен жауаптар жазылған хат келеді.

Бұл тегін әрі сервер қажет етпейді. Бапталуы шамамен 5 минут алады және бір рет қана жасалады.

### 1-қадам. Кесте құру

1. <https://sheets.google.com> сайтында жаңа кесте ашыңыз. Мысалы, оны «GreenChemAI — жауаптар» деп атаңыз.
2. Мәзірден **Кеңейтімдер → Apps Script** (Extensions → Apps Script) тармағын ашыңыз.

### 2-қадам. Кодты қою

1. Ашылған редактордағы `Code.gs` файлының барлық мазмұнын өшіріңіз.
2. Оның орнына [`integrations/google-apps-script/Code.gs`](../integrations/google-apps-script/Code.gs) файлының мазмұнын толық көшіріп қойыңыз.
3. Жоғарғы жолдағы `ORGANIZER_EMAIL` мәнін өз поштаңызға ауыстырыңыз:
   ```js
   const ORGANIZER_EMAIL = "sizdin.poshta@university.kz";
   ```
4. 💾 **Сақтау** батырмасын басыңыз.

### 3-қадам. Рұқсат беру және тексеру

1. Функциялар тізімінен `testSetup` функциясын таңдап, ▶ **Іске қосу** (Run) батырмасын басыңыз.
2. Google рұқсат сұрайды. Өз аккаунтыңызды таңдап, **Advanced → Go to … (unsafe) → Allow** батырмаларын басыңыз. Скриптті өзіңіз жасағандықтан, Google осылай ескертеді.
3. Кестеде «Жауаптар» парағы мен сынақ жолы пайда болуы керек, ал поштаңызға сынақ хат келеді.

### 4-қадам. Веб-қосымша ретінде жариялау

1. **Deploy → New deployment** батырмасын басыңыз.
2. ⚙ белгісі арқылы **Web app** түрін таңдаңыз.
3. Баптауларды толтырыңыз:
   - **Execute as:** *Me* (өзіңіз)
   - **Who has access:** *Anyone*
4. **Deploy** батырмасын басып, **Web app URL** сілтемесін көшіріңіз. Ол `https://script.google.com/macros/s/…/exec` түрінде болады.

### 5-қадам. URL-ді сайтқа қосу

1. GitHub-та [`public/js/config.js`](../public/js/config.js) файлын ашып, ✏️ (Edit) батырмасын басыңыз.
2. Мәндерді толтырыңыз:
   ```js
   organizerName: "Аты-жөніңіз",
   organizerEmail: "sizdin.poshta@university.kz",
   submitUrl: "https://script.google.com/macros/s/…/exec",
   ```
3. **Commit changes** батырмасын басыңыз. 1–2 минуттан кейін сайт жаңарады.

Енді студент тест немесе кейс тапсырғанда нәтиже бетінде «📨 Ұйымдастырушыға жіберілді» деген жазу шығады.

### Ескертпелер

- **Кодты кейін өзгертсеңіз**, **Deploy → Manage deployments → ✏️ → Version: New version → Deploy** жолымен қайта жариялаңыз. URL өзгермейді.
- **Google-дың тегін шектеуі** тәулігіне шамамен 100 хат. Студенттер көп болса, `SEND_EMAIL = false` қойыңыз. Сонда нәтижелер тек кестеге жиналады.
- **Студентке көшірме** жіберу үшін `SEND_COPY_TO_STUDENT = true` қойыңыз. Ол студент email енгізген жағдайда ғана жұмыс істейді.
- **Интернет болмаса**, жұмыс студенттің браузерінде кезекке қойылады. Байланыс қалпына келгенде ол автоматты түрде қайта жіберіледі.
- **`submitUrl` бос болса**, нәтижелер тек студенттің құрылғысында сақталады. Бұл жағдайда студентке «📧 Поштамен жіберу» (`organizerEmail` көрсетілсе) және «⬇ Файл ретінде жүктеу» батырмалары шығады.
- **Тест кілттері туралы.** Бұл статикалық сайт, сондықтан тесттің дұрыс жауаптары браузер кодында сақталады. Техникалық білімі бар студент оларды көре алады. Қорытынды бағалау үшін кестедегі толық жауаптарды, кейстердің ашық жауаптарын және ауызша қорғауды бірге қолданған дұрыс.

## 2. Лекция материалдарын қосу

Материалдар `public/lectures/` қалтасында сақталады. Сайттағы «Лекциялар» бөлімі осы қалтадан тізімді автоматты түрде құрастырады.

### Файл жүктеу

1. GitHub-та **public → lectures** қалтасын ашыңыз.
2. **Add file → Upload files** батырмасын басып, файлдарды сүйреп әкеліңіз.
3. **Commit changes** батырмасын басыңыз. 1–2 минуттан кейін файл сайтта пайда болады.

Қолдау көрсетілетін форматтар:

| Түрі | Кеңейтімдер | Сайтта қалай көрінеді |
|---|---|---|
| PDF | `.pdf` | Сайттың ішінде ашылады |
| Презентация, құжат, кесте | `.pptx`, `.docx`, `.xlsx` | Microsoft Office Online арқылы қаралады және жүктеледі |
| Бейне, аудио | `.mp4`, `.webm`, `.mp3` | Сайттағы ойнатқышта ашылады |
| Басқалары | `.zip`, `.png`, `.jpg` | Жүктеледі |

**Файл атауы.** Атаудың басына нөмір қойыңыз. Ол тізімдегі ретті анықтайды, ал атаудың қалған бөлігі тақырып ретінде көрсетіледі. Мысалы, `02-atomdyk-unemdilik.pdf` файлы тізімде «Atomdyk unemdilik» деп көрінеді. Қазақша атауды `lectures.json` арқылы беруге болады (төменде).

**Көлемі.** Браузер арқылы жүктелетін бір файл 25 МБ-тан аспауы керек. Ұзақ бейнелерді YouTube-қа жүктеп, сілтемесін қосыңыз.

### Атау, апта, сипаттама және сілтемелер: `lectures.json`

`public/lectures/lectures.json` файлын өңдеңіз:

```json
{
  "items": [
    {
      "file": "02-atomdyk-unemdilik.pdf",
      "title": "2-дәріс. Атомдық үнемділік және E-фактор",
      "module": "2-апта",
      "description": "Метрикалардың анықтамасы, шығарылған есептер"
    },
    {
      "url": "https://www.youtube.com/watch?v=XXXXXXXXXXX",
      "title": "Бейнедәріс: Катализ",
      "module": "3-апта",
      "order": 3
    }
  ]
}
```

- `file`: `public/lectures/` қалтасындағы файлдың аты. Ол файл атауымен дәл сәйкес келуі керек.
- `url`: сыртқы сілтеме. YouTube сілтемесі сайттың ішінде ойнатылады, ал Google Drive және басқа сілтемелер жаңа бетте ашылады.
- `module`: топтау атауы, мысалы «1-апта».
- `order`: тізімдегі реті.

JSON синтаксисіне мұқият болыңыз: үтірлер мен тырнақшалар дұрыс қойылуы керек. Синтаксис қате болса, файл атаулары автоматты түрде қолданылады.

## 3. Тест сұрақтарын өзгерту

Сұрақтар [`public/js/data/quizzes.js`](../public/js/data/quizzes.js) файлында сақталады. Әр тесттің баптаулары:

- `passPercent`: өту шегі (%);
- `attempts`: талпыныс саны;
- `timeLimit`: уақыт шегі (минут). `null` қойсаңыз, уақыт шектелмейді;
- `count`: әр талпыныста кездейсоқ таңдалатын сұрақ саны (қорытынды емтиханда қолданылады).

Сұрақ түрлері:

- `single`: бір дұрыс жауап;
- `multi`: бірнеше дұрыс жауап;
- `number`: сандық жауап. Дәлдігі `tol` арқылы беріледі, мысалы `0.01` = ±1%.

Файлды өзгерткен соң, `npm test` командасы құрылымды тексереді.

## 4. «Қазақстан өндірістері» бөліміне өндіріс қосу

1. Ақпараттық бетті `public/industries/indN.html` файлына салыңыз (N — өндіріс нөмірі). Файлда тек `<section class="card">…</section>` бөлімдері болады. Үлгі ретінде `ind1.html` файлын алыңыз.
2. `public/js/data/industries.js` файлында сол өндірістің жазбасына `ready: true`, `lead` және `tasks` қосыңыз.
3. Әр тапсырма мынадай өрістерден тұрады:
   - `level`: деңгей — `"A"` (білу), `"B"` (талдау) немесе `"C"` (шешім);
   - `type`: `"text"` (ашық жауап) немесе `"number"` (сандық жауап және есептеу жолы). Сандық тапсырмада `parts` тізімі беріледі: әр сан үшін `key`, `label`, `answer`, `tol`, `unit`. Бір тапсырмада бірнеше сан сұралса, тізімге бірнеше жазба қосылады;
   - `minWords`: ұсынылатын сөз саны;
   - `ai: true`: AI-кеңесшіге сілтеме қосу.

Студент жауаптары оқытушыға «ҚР өндірісі» түрімен жіберіледі. Сандық жауаптар автоматты тексеріледі, ал ашық жауаптарды оқытушы бағалайды.
